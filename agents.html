Agents

A first test of what an AI agent might do inside this project. For now it is a plain interface to a language model: a question in, an answer back. The exercise is learning what it takes to connect one to a page at all.

The intent is an agent that knows this project's material, so a visitor can ask for precisely what they need (how many sidewalk sheds stand in a given neighborhood, what the survey responses show so far) rather than reading through every tab to find it. Less browsing, more asking.
